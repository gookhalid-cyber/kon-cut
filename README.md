# Kon Cut 🎬

مونتاج دسكتوب أصلي بـ Electron + FFmpeg، بواجهة عربية قريبة من CapCut. مفيش كود أو أصول منسوخة من أي برنامج تجاري — الأفكار بس مستوحاة من أحسن البرامج المفتوحة.

## التشغيل

من مجلد `montaj-studio`:

```bat
run.bat
```

أو:

```bat
npm start
```

> لو `node` مش معروف في الـ terminal، استخدم `run.bat` — بيضيف مسار Node تلقائياً.

## اللي شغال دلوقتي

- واجهة CapCut-style: شريط أيقونات، تبويبات (وسائط / صوت / نص / انتقالات / تأثيرات / فلاتر / ماسكات / ضبط)، لوحة خصائص.
- **ماسكات أصلية** (دائرة، مستطيل، قلب، نجمة، مثلث، ماس، تدرّج، مرآة) مع معاينة حيّة عند المرور، وتطبيق على المقطع المحدد، وتصدير فعلي في MP4.
- **Keyframes** للحركة (موضع، حجم، دوران، شفافية) مع أنيميشن جاهز: دخول / خروج / نبضة / انزلاق، ونقاط مفتاحية على الخط الزمني. متصدّرة في النص عبر ASS transforms.
- **تغيير السرعة** (0.25× → 4×) مع `setpts` و `atempo` في التصدير.
- **انتقالات حقيقية في التصدير** (تلاشي أسود/أبيض/رمادي ووميض) مش بس في المعاينة.
- أيقونات متحركة، ومعاينة فورية للساوندات والفلاتر والنصوص والانتقالات والماسكات.
- 6 مؤثرات صوتية أصلية في `assets\sfx` (متولّدة بـ `tools\generate_sfx.py`).
- 8 ماسكات أصلية في `assets\masks` (متولّدة بـ `tools\generate_masks.py`).
- استيراد فيديو/صوت/صور، سحب للخط الزمني، تحريك، تقليم، تقسيم، محاذاة تلقائية، مصغّرات حقيقية بـ FFmpeg.
- صوت الفيديو والساوندات شغالة أثناء التشغيل، ومعاينة بـ Play مستمر بدون تقطيع.
- نصوص عربية (Cairo) + حفظ/فتح `.montaj` + تصدير MP4 (H.264 + AAC) بشريط تقدم.

## ملاحظات تقنية

- FFmpeg و ffprobe موجودان في `C:\Users\Elmodather\AppData\Local\Programs\FFmpeg\...`، أو ضعهم في `bin\` أو استخدم المتغير `KONCUT_FFMPEG`.
- الخطوط في `assets\fonts`، المؤثرات في `assets\sfx`، الماسكات في `assets\masks`.
- منطق FFmpeg في `ffmpeg-builder.js` منفصل عن Electron عشان يتختبر لوحده: `node test-export.js`.
- المشروع على GitHub باسم **Kon Cut** (المستودع: `kon-cut`).

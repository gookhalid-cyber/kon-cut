# Kon Cut 🎬

مونتاج دسكتوب أصلي بـ Electron + FFmpeg، بواجهة عربية قريبة من CapCut. مفيش كود أو أصول منسوخة من أي برنامج تجاري — الأفكار بس مستوحاة من أحسن البرامج المفتوحة.

## التشغيل

من مجلد `montaj-studio`:

```bat
run.bat
```

أو:

```bat
npm start
```

> لو `node` مش معروف في الـ terminal، استخدم `run.bat` — بيضيف مسار Node تلقائياً.

## اللي شغال دلوقتي

- واجهة CapCut-style: شريط أيقونات، تبويبات (وسائط / صوت / نص / انتقالات / تأثيرات / فلاتر / ماسكات / ضبط)، لوحة خصائص.
- **ماسكات أصلية** (دائرة، مستطيل، قلب، نجمة، مثلث، ماس، تدرّج، مرآة) مع معاينة حيّة عند المرور، وتطبيق على المقطع المحدد، وتصدير فعلي في MP4.
- **اتجاه الماسك**: «داخل IN» بيظهر الجزء جوّه الشكل، و«خارج OUT» بيظهر الجزء برّه الشكل — قابل للتبديل في لوحة الخصائص أو بـ keyframe.
- **Keyframes للماسك**: الشكل، الاتجاه (داخل/خارج)، الموضع أفقي/رأسي، الاتجاه°، الحجم، فتح/قفل، ونعومة الحافة — كلهم ليهم زر ◇ صغير في لوحة الخصائص لإضافة نقطة مفتاحية عند رأس التشغيل، وبيتحركوا في المعاينة والتصدير.
- **تعديل الماسك من شاشة العرض**: لما ماسك يكون مفعّل على المقطع المحدد، مقابض على المعاينة: أصفر للتحريك، أزرق للحجم، أخضر للدوران، وردي للفتح/القفل — اسحبهم مباشرة واللوحة والمعاينة والتصدير بيتحدثوا فوراً (حتى لو فيه keyframe عند رأس التشغيل).
- **عزل ذكي للخلفية والأشخاص**: زرّين 🪄 / 🧍 تحت المعاينة (أو من قائمة الكليك الأيمن ولوحة الخصائص) بيولّدوا matte رمادي للمقطع أو الصورة المحدّدة — وضع `general` لعزل أي جسم، ووضع `person` لعزل الأشخاص بالتحديد. الـ matte بيشتغل في المعاينة والتصدير، وبيدمج مع الماسكات والـ IN/OUT والـ keyframes.
- **Keyframes للحركة** (موضع، حجم، دوران، شفافية) مع أنيميشن جاهز: دخول / خروج / نبضة / انزلاق، ونقاط مفتاحية على الخط الزمني. متصدّرة في النص عبر ASS transforms.
- **أدوات تحت المعاينة**: تجميد الإطار (❄ / `F`)، مرآة أفقية (↔ / `M`)، انعكاس رأسي، وعكس المقطع (⏪ / `R`)، والتقسيم (`S`) — وكلهم كمان في قائمة الكليك الأيمن على المعاينة أو على المقطع. اختصار `S` شغال حتى لو الفوكس على slider في لوحة الخصائص.
- **سحب CapCut-style على الخط الزمني**: تحريك بين المسارات، مقابض قص من اليسار واليمين، محاذاة تلقائية، ودفع المقاطع اللي بعدك (ripple) لما تحط مقطع في النص.
- **تغيير السرعة** (0.25× → 4×) مع `setpts` و `atempo` في التصدير.
- **انتقالات حقيقية في التصدير** (تلاشي أسود/أبيض/رمادي ووميض) مش بس في المعاينة.
- أيقونات متحركة، ومعاينة فورية للساوندات والفلاتر والنصوص والانتقالات والماسكات.
- 6 مؤثرات صوتية أصلية في `assets\sfx` (متولّدة بـ `tools\generate_sfx.py`).
- 8 ماسكات أصلية في `assets\masks` (متولّدة بـ `tools\generate_masks.py`).
- استيراد فيديو/صوت/صور، سحب للخط الزمني، تحريك، تقليم، تقسيم، محاذاة تلقائية، مصغّرات حقيقية بـ FFmpeg.
- **مراقبة صوت احترافية (Fairlight-style)**: LED + عدّاد مستوى حي (VU meter) بيورّي لو الصوت شغال، مع زر «تجربة» وجهاز إخراج قابل للاختيار.
- **تحكم كامل لكل مسار**: مستوى صوت (0–150%)، كتم (Mute)، وعزل (Solo)، مع تحكم عام (Master + كتم) — كلهم متناغمين عبر Web Audio graph.
- صوت الفيديو والساوندات شغالة أثناء التشغيل، ومعاينة بـ Play مستمر بدون تقطيع.
- **تراجع/إعادة (Undo/Redo)**: زرّين ↶ / ↷ في الشريط + `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`. كل تعديل (إضافة، حذف، تقسيم، تحريك، قص، ماسك، keyframe، عزل، فلتر، ضبط، صوت، سرعة…) بيتسجّل تلقائياً، والتعديلات المتواصلة (slider/scrub) بتتجمع في خطوة واحدة.
- **حفظ تلقائي (Autosave)**: بعد كل تعديل بيتكتب ملف `.autosave.montaj` جنب المشروع، وزر «نسخة احتياطية» بيفتحه. الملف بيسترجع الأصول المولّدة (تجميد/عكس/عزل) حتى لو اتمسحت من `temp`.
- **الفلاتر والضبط مطبّقة في التصدير**: بريسِتس الألوان والسطوع/التباين/التشبّع/الحرارة محفوظة داخل المشروع ومترجَمة لـ `eq` / `hue` / `colorchannelmixer` في FFmpeg — اللي تشوفه في المعاينة هو اللي بيطلع في MP4.
- **Waveforms للصوت**: قمم صوت حقيقية بتتستخرج من FFmpeg وتتخزّن في الذاكرة، وترسم جوه مقاطع الصوت والفيديو اللي فيها صوت — بتتحرك مع القص والسرعة ونقطة الدخول.
- **Fades صوتية**: تلاشي دخول/خروج لكل مقطع (`afade` في التصدير، وتحكم في الـ gain أثناء المعاينة).
- **Keyframes للصوت**: زر ◇ جنب مستوى الصوت بيضيف نقطة مفتاحية، والمستوى بيتحرك بـ `volume=eval=frame` في التصدير — بنفس منحنى المعاينة.
- **مناحني keyframes**: كل نقطة ليها اختيار «خطي / تسارع / تباطؤ / تسارع وتباطؤ». نفس دالة الـ easing مشتركة بين `kf-easing.js` في المعاينة وفي أوامر FFmpeg، فمفيش انحراف بين اللي تشوفه واللي يتصدّر. الضغط على الوقت بينقل رأس التشغيل للنقطة.
- **تحرير متعدد**: تحديد بـ Shift (مدى) وCtrl/Cmd (إضافة/إزالة) وCtrl+A (الكل)، تكرار `Ctrl+D`، نسخ `Ctrl+C`، لصق `Ctrl+V`، حذف عادي أو `Shift+Delete` للمسح مع دفع باقي المقاطع للخلف (ripple).
- **تحكم في المسارات**: قفل/فتح المسار (🔒)، تحريكه لأعلى/أسفل (▲/▼)، وكمان الإجراءات دول في قائمة الكليك الأيمن.
- **إعدادات تصدير controllable**: دقة (أفقي/عمودي/مربع)، معدل إطارات (24–60)، وجودة (CRF 18/23/28) قبل بدء التصدير.
- **إلغاء العمليات**: زر «إلغاء العملية» بيوقف التصدير أو العزل الذكي في نص الطريق، مع إغلاق كل عمليات FFmpeg/Python التابعة.
- **تطبيع الصوت وتقليل الضوضاء**: تطبيع بقمم الصوت (نفس الجهد في المعاينة والتصدير)، و`afftdn` في التصدير مع تقريب عبر Web Audio في المعاينة.
- **Curve editor مصغّر**: منحنيات linear / easeIn / easeOut / easeInOut مرسومة على لوحة الحركة، والضغط على المنحنى بيغيّر الانتقال للنقطة المختارة.
- **Proxies تلقائية**: نسخ 480p بكل الإطارات keyframes للمعاينة السريعة، والتصدير دايماً من الملف الأصلي. الـ seek بيستنى أول إطار فعلي عبر `requestVideoFrameCallback`، مع cache محدود للإطارات.
- **تبديل الخلفية بعد العزل**: اختار صورة أو فيديو كخلفية، مع نعومة حافة (feather) وتنعيم زمني للـ matte (`tmix`) — شغالين في المعاينة والتصدير.
- **أدوات ذكية**: كشف تغيّر المشاهد (`select=gt(scene,0.4)`) مع علامات على المسطرة وتقسيم تلقائي، وكشف الصمت (`silencedetect`) مع حذف وتعويض (ripple).
- **ترجمة عربية محلية**: استخراج نص من المقطع المحدد عبر Whisper small int8 محزّم، وتحويله لتقطيعات نص على مسار النصوص — من غير إنترنت.
- **تقارير أخطاء محلية**: لوج في `%LOCALAPPDATA%\Kon Cut\logs\kon-cut.log` وزر «نسخ تقرير الأخطاء» — مفيش أي إرسال خارجي.
- **تغليف جاهز**: installer NSIS + نسخة portable، مع FFmpeg وPython وONNX models وWhisper جوه الحزمة.
- نصوص عربية (Cairo) + حفظ/فتح `.montaj` + تصدير MP4 (H.264 + AAC) بشريط تقدم.

## ملاحظات تقنية

- FFmpeg و ffprobe بيتقراو من `bin\` أولاً. لو مش موجودين فحطهم في `bin\` أو ضع المتغير `KONCUT_FFMPEG_DIR` (مجلد bin). المتغير `KONCUT_FFMPEG` لسه بيشتغل كـ override مباشر.
- العزل الذكي والترجمة بيستخدموا Python محزّم في `runtime\python` (أو `KONCUT_PYTHON`). النماذج في `runtime\models`: `isnet-general-use` و`u2net_human_seg` و`u2netp` للعزل، و`whisper/small` للترجمة. سكربت `tools\remove_bg.py` بيقرأ raw RGB من FFmpeg وبيكتب matte رمادي.
- لتجهيز مجلد `runtime` و`bin` من الصفر:
  ```bat
  npm run prepare:runtime
  ```
  السكربت بينزّل Python embeddable و`rembg[cpu]` و`pymatting` و`faster-whisper` والنماذج، وبينسخ FFmpeg من `KONCUT_FFMPEG_DIR`.
- بناء Installer + Portable:
  ```bat
  npm run dist:full
  ```
  الناتج في `dist\`. GitHub Actions بيعمل نفس الخطوات في `.github\workflows\build.yml` عند دفع tag `v*`.
- الخطوط في `assets\fonts`، المؤثرات في `assets\sfx`، الماسكات في `assets\masks`.
- منطق FFmpeg في `ffmpeg-builder.js` منفصل عن Electron عشان يتختبر لوحده. الاختبارات المتاحة:
  ```bat
  npm run test:all
  ```
  بتشغّل كل اختبارات الوحدة (history / paths / filters / audio / export / segment / AI) وبعدين `test-ui.mjs` — اختبار CDP لواجهة Electron على profile منفصل.
- اختبار النسخة المغلّفة نفسها (بعد `npm run dist` أو `dist:full`) بيفحص إن FFmpeg والنماذج والترجمة شغّالين من `resources\` من غير نت:
  ```bat
  npm run test:packaged
  ```
- الأصول المولّدة (إطار مجمد، مقطع معكوس، matte عزل) بتتنقل تلقائياً لمجلد `<اسم المشروع>_assets` جنب ملف `.montaj`، والمسارات بتتخزّن نسبية عشان المشروع يفتح على أي جهاز.
- المشروع على GitHub باسم **Kon Cut** (المستودع: `kon-cut`).

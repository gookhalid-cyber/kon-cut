# Kon Cut 🎬

مونتاج دسكتوب أصلي بـ Electron + FFmpeg، بواجهة عربية قريبة من CapCut. مفيش كود أو أصول منسوخة من أي برنامج تجاري — الأفكار بس مستوحاة من أحسن البرامج المفتوحة.

## التشغيل

من مجلد `montaj-studio`:

```bat
run.bat
```

أو:

```bat
npm start
```

> لو `node` مش معروف في الـ terminal، استخدم `run.bat` — بيضيف مسار Node تلقائياً.

## اللي شغال دلوقتي

- واجهة CapCut-style: شريط أيقونات، تبويبات (وسائط / صوت / نص / انتقالات / تأثيرات / فلاتر / ماسكات / ضبط)، لوحة خصائص.
- **ماسكات أصلية** (دائرة، مستطيل، قلب، نجمة، مثلث، ماس، تدرّج، مرآة) مع معاينة حيّة عند المرور، وتطبيق على المقطع المحدد، وتصدير فعلي في MP4.
- **اتجاه الماسك**: «داخل IN» بيظهر الجزء جوّه الشكل، و«خارج OUT» بيظهر الجزء برّه الشكل — قابل للتبديل في لوحة الخصائص أو بـ keyframe.
- **Keyframes للماسك**: الشكل، الاتجاه (داخل/خارج)، الموضع أفقي/رأسي، الاتجاه°، الحجم، فتح/قفل، ونعومة الحافة — كلهم ليهم زر ◇ صغير في لوحة الخصائص لإضافة نقطة مفتاحية عند رأس التشغيل، وبيتحركوا في المعاينة والتصدير.
- **عزل ذكي للخلفية والأشخاص**: زرّين 🪄 / 🧍 تحت المعاينة (أو من قائمة الكليك الأيمن ولوحة الخصائص) بيولّدوا matte رمادي للمقطع أو الصورة المحدّدة — وضع `general` لعزل أي جسم، ووضع `person` لعزل الأشخاص بالتحديد. الـ matte بيشتغل في المعاينة والتصدير، وبيدمج مع الماسكات والـ IN/OUT والـ keyframes.
- **Keyframes للحركة** (موضع، حجم، دوران، شفافية) مع أنيميشن جاهز: دخول / خروج / نبضة / انزلاق، ونقاط مفتاحية على الخط الزمني. متصدّرة في النص عبر ASS transforms.
- **أدوات تحت المعاينة**: تجميد الإطار (❄ / `F`)، مرآة أفقية (↔ / `M`)، انعكاس رأسي، وعكس المقطع (⏪ / `R`) — وكلهم كمان في قائمة الكليك الأيمن على المعاينة أو على المقطع.
- **سحب CapCut-style على الخط الزمني**: تحريك بين المسارات، مقابض قص من اليسار واليمين، محاذاة تلقائية، ودفع المقاطع اللي بعدك (ripple) لما تحط مقطع في النص.
- **تغيير السرعة** (0.25× → 4×) مع `setpts` و `atempo` في التصدير.
- **انتقالات حقيقية في التصدير** (تلاشي أسود/أبيض/رمادي ووميض) مش بس في المعاينة.
- أيقونات متحركة، ومعاينة فورية للساوندات والفلاتر والنصوص والانتقالات والماسكات.
- 6 مؤثرات صوتية أصلية في `assets\sfx` (متولّدة بـ `tools\generate_sfx.py`).
- 8 ماسكات أصلية في `assets\masks` (متولّدة بـ `tools\generate_masks.py`).
- استيراد فيديو/صوت/صور، سحب للخط الزمني، تحريك، تقليم، تقسيم، محاذاة تلقائية، مصغّرات حقيقية بـ FFmpeg.
- **مراقبة صوت احترافية (Fairlight-style)**: LED + عدّاد مستوى حي (VU meter) بيورّي لو الصوت شغال، مع زر «تجربة» وجهاز إخراج قابل للاختيار.
- **تحكم كامل لكل مسار**: مستوى صوت (0–150%)، كتم (Mute)، وعزل (Solo)، مع تحكم عام (Master + كتم) — كلهم متناغمين عبر Web Audio graph.
- صوت الفيديو والساوندات شغالة أثناء التشغيل، ومعاينة بـ Play مستمر بدون تقطيع.
- نصوص عربية (Cairo) + حفظ/فتح `.montaj` + تصدير MP4 (H.264 + AAC) بشريط تقدم.

## ملاحظات تقنية

- FFmpeg و ffprobe موجودان في `C:\Users\Elmodather\AppData\Local\Programs\FFmpeg\...`، أو ضعهم في `bin\` أو استخدم المتغير `KONCUT_FFMPEG`.
- العزل الذكي يحتاج Python 3.12 مع `rembg[cpu]` و`pymatting`:
  ```bat
  C:\Users\Elmodather\AppData\Local\Programs\Python\Python312\python.exe -m pip install "rembg[cpu]" pymatting
  ```
  أو حط مسار Python في المتغير `KONCUT_PYTHON`. أول تشغيل بينزّل نماذج `isnet-general-use` و`u2net_human_seg` في `%USERPROFILE%\.rembg\models` (~350MB). سكربت التوليد في `tools\remove_bg.py` بيقرأ raw RGB من FFmpeg وبيكتب matte رمادي.
- الخطوط في `assets\fonts`، المؤثرات في `assets\sfx`، الماسكات في `assets\masks`.
- منطق FFmpeg في `ffmpeg-builder.js` منفصل عن Electron عشان يتختبر لوحده: `node test-export.js`.
- المشروع على GitHub باسم **Kon Cut** (المستودع: `kon-cut`).
